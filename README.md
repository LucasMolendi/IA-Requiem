# IA-Requiem
## Contexte
Création d'une IA analysant les résultant transmis par des sondes et conseil des utilisateurs pour une meilleure gestion de leurs plantes.
Ce projet fait partie du projet final de B2.
### Front et Back de l'app
- Front (Angular): [ici](https://github.com/Deezay10/front_requiem)
- Back (Java Spring boot): [ici](https://github.com/Vladimir-clic/back_requiem)

## Matériel utilisée
- VM ubuntu server Front
- VM ubuntu server Back
- VM ubuntu server BDD
- raspberry pi home assistant
- clé zigbee
- VM OPNSense
